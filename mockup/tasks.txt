1. Don't make the LLM generate an actual .xlsx

This is important.

Have the LLM generate structured JSON, not Excel.

For example, conceptually:

{
  title: "Lesson Plan: Fractions",
  grade_level: "Grade 6",
  subject: "Mathematics",
  duration: "60 minutes",
  objectives: [...],
  activities: [...],
  assessment: {...}
}

Then your Laravel application converts that structured data into whatever format you need:

HTML/table for viewing
database records
.xlsx for download

This gives you much more control.

2. Your React UI can look like Excel

You don't actually need to embed Microsoft Excel.

You can use an Excel-like React grid.

For example, the screen could have:

┌─────────────────────────────────────────────────────────────┐
│ Mentora — AI Lesson Plan Creator                            │
├─────────────────────────────────────────────────────────────┤

│ │ Objectives │ Activities   │ Resources    │ Assessment   │ │

│ │ ...        │ ...          │ ...          │ ...          │ │

The teacher can modify the AI's output before saving/publishing.

That's actually very good for your paper because it demonstrates human validation.

3. I would structure your lesson plan around the Philippine school context

Don't just ask:

"Generate a lesson plan."

Give Mentora structured information:

Grade Level
Subject
Topic
Learning Competency
Learning Objectives
Duration
Teaching Strategy
Available Resources
Assessment Type

Then your LLM prompt can essentially say:

Generate a lesson plan using only the provided educational context. Follow the specified learning competency and objectives. Do not invent curriculum standards that are not present in the provided context.

That makes your RAG/context-aware component actually meaningful.

7. .xlsx export

For Laravel, I'd use PhpSpreadsheet or Laravel Excel rather than trying to generate Excel manually.

Your flow becomes:

LLM JSON
     ↓
LessonPlan model
     ↓
Laravel Excel/PhpSpreadsheet
     ↓
lesson-plan.xlsx

And your React button simply calls:

GET /api/lesson-plans/{id}/export

The browser downloads the generated file.

8. But you said you want an XLSX VIEWER

There are actually two different things:

A. Excel-like editor

Teacher sees:

| Objectives | Activities | Resources | Assessment |

I recommend this.

Teacher uploads an existing Excel file and Mentora renders it.

10. The most important part for your capstone

Your workflow should explicitly show:

AI → Teacher → Final Output

not:

AI → Final Grade/Lesson

For lesson plans:
